# Pricing Strategy

## Pricing Principle

DALC pricing should signal control, trust, and execution quality.

The product should not look cheap, but it also should not hide everything behind vague "contact us" language. The correct approach is selective visibility:

1. show price when the offer is standardized and trust-building
2. hide price when scope, speed, or coordination materially changes the economics

## Pricing Framework

| Offer type | Pricing approach |
| --- | --- |
| Standardized high-trust entry | Visible fixed price |
| Complex transformation | Consultation then package |
| Premium custom execution | Quote-led |
| Repeat premium support | Recurring membership or retainer |

## 1. Consultations

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Fixed visible price to create trust and urgency |
| Suggested range | AED 950-1,500 for focused 45-60 minute expert consultation |
| Margin profile | Very high margin |
| Customer psychology | Users pay when the consultation removes confusion and gives a real path forward |
| Show price or hide? | Show price |
| How to avoid looking cheap | Frame as a strategic working session, not a discovery call |

## 2. Relocation Packages

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Package-based pricing tied to complexity and dependency count |
| Suggested range | AED 7,500-25,000+ DALC fee, excluding certain third-party government or supplier costs |
| Margin profile | Strong margin if DALC owns coordination and partner routing |
| Customer psychology | Users want certainty and ownership, not open-ended hourly billing |
| Show price or hide? | Show "starting from" only; final price after consultation |
| How to avoid looking cheap | Sell outcome ownership, not generic move assistance |

## 3. Business Setup Packages

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Package pricing built around setup path, jurisdiction complexity, and admin load |
| Suggested range | AED 5,000-18,000+ DALC fee before official government or third-party costs |
| Margin profile | High margin if DALC structures the process and partners intelligently |
| Customer psychology | Founders pay for speed, correctness, and reduced operational noise |
| Show price or hide? | Consultation first, then quote or package |
| How to avoid looking cheap | Emphasize commercially serious execution, not bargain setup claims |

## 4. Concierge Services

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Minimum execution fee plus custom quote where needed |
| Suggested range | AED 500-1,500 minimum service fee for custom coordination, then quote-based for larger requests |
| Margin profile | Good if DALC prices coordination explicitly instead of relying only on partner commissions |
| Customer psychology | High-value users accept fees when DALC clearly saves time and complexity |
| Show price or hide? | Show minimum fee rule; hide full custom pricing until scoped |
| How to avoid looking cheap | Make the fee about execution ownership, not access to a contact list |

## 5. Lifestyle Planning

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Small planning fee for curated premium itineraries or complex bundles |
| Suggested range | AED 750-3,000 depending on depth and urgency |
| Margin profile | High margin if planning is sold separately from booking revenue |
| Customer psychology | Users pay when the plan is curated, not when it feels like generic recommendations |
| Show price or hide? | Show planning-from pricing only on premium requests |
| How to avoid looking cheap | Position planning as a private curation layer, not a travel itinerary PDF |

## 6. Membership Tiers

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Recurring tiers tied to service priority and repeat usage economics |
| Suggested range | Core AED 1,500/month, Premium AED 4,000/month, Elite custom |
| Margin profile | Excellent if operator capacity and priority logic are controlled |
| Customer psychology | Membership works only when the user already trusts DALC and expects repeat value |
| Show price or hide? | Show tiers only after DALC proves service value or when the user is clearly qualified |
| How to avoid looking cheap | Tie pricing to priority handling and continuity, not generic perks |

## 7. Premium Execution Fees

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Add execution fees to high-touch or multi-step requests |
| Suggested range | AED 1,000 minimum or 10-20% service fee depending on complexity |
| Margin profile | Strong if clearly attached to coordination value |
| Customer psychology | Clients accept execution fees when DALC is clearly taking ownership |
| Show price or hide? | Hide until request scope is understood |
| How to avoid looking cheap | Never describe this as an admin fee; describe it as execution management |

## 8. Rush Fees

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Urgency surcharge on requests with compressed timelines or out-of-hours handling |
| Suggested range | 20-35% uplift or minimum AED 1,000 |
| Margin profile | Very strong |
| Customer psychology | Premium users expect urgency to cost more if the result is real responsiveness |
| Show price or hide? | Show rule, not always the exact amount |
| How to avoid looking cheap | Frame as priority execution, not penalty pricing |

## 9. Partner Commissions

| Dimension | Recommendation |
| --- | --- |
| Pricing logic | Category-specific commission structure |
| Suggested range | 10-25% depending on category, ticket size, and partner dependence |
| Margin profile | Useful but should remain secondary to owned revenue |
| Customer psychology | Usually invisible to user if DALC is still competitively priced |
| Show price or hide? | Do not surface as customer-facing pricing |
| How to avoid looking cheap | Do not let partner commissions become the only monetization story |

## When To Show Price Versus Hide It

| Show price | Hide behind consultation or quote |
| --- | --- |
| Consultations | Relocation packages |
| Standardized small planning fees | Business setup packages |
| Minimum concierge execution fee | Multi-service custom requests |
| Entry membership pricing for qualified users | Elite or bespoke premium support |

## How To Avoid Looking Cheap While Still Converting

1. Use price floors, not bargain anchors.
2. Package around outcomes, not line items.
3. Make paid consultation feel like a strategic decision session.
4. Use "starting from" only where scope genuinely changes.
5. Tie premium pricing to faster execution, ownership, and clarity.

DALC should never compete on lowest price. It should compete on speed, control, and confidence.
