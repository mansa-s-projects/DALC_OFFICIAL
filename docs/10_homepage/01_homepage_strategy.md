# Homepage Strategy

## Homepage Job

The homepage should not sell DALC as a luxury browsing destination.

The homepage should do three things:

1. explain the category in seconds
2. convert high-intent users into command input or consultation
3. prove that DALC is an execution layer, not a content layer

## Hero Strategy

The hero should position DALC as the command layer for Dubai.

That means the hero needs:

1. a category-defining headline
2. a subheadline that explains execution, not curation
3. a command-style input as the primary interaction
4. proof that DALC handles real outcomes across relocation, business, and premium lifestyle execution

## Headline Options

1. The Operating System For Life In Dubai
2. From Intent To Execution In Dubai
3. The Command Layer For Moving, Building, And Living In Dubai
4. Tell DALC What You Need In Dubai. DALC Gets It Done.

## Subheadline Options

1. DALC turns relocation, business setup, concierge, and premium lifestyle requests into executed outcomes through AI decisioning and human operators.
2. Stop stitching Dubai together through search, brokers, and WhatsApp threads. DALC interprets the need, routes the work, and drives execution.
3. One system for moving to Dubai, starting in Dubai, and operating in Dubai without fragmented providers and manual coordination.

## Command Input Strategy

The command input should be the main conversion surface.

It should feel like the front door to an operating system, not a search bar.

Requirements:

1. strong placeholder examples
2. immediate confidence-building around what DALC can handle
3. a next step that feels intelligent and structured, not generic

Best input examples:

1. I want to move to Dubai with my family by September
2. I need help setting up a company in Dubai
3. I need a driver, hotel, and dinner plan for this weekend
4. I need a yacht tomorrow for 12 people

## Section-By-Section Structure

| Section | Purpose |
| --- | --- |
| Hero | Define the category and drive command input |
| Problem section | Explain why Dubai demand is fragmented and why current solutions fail |
| How DALC works | Show the intent -> decision -> execution loop |
| Core use cases | Highlight relocation, business setup, concierge, and premium execution |
| Trust and proof | Show seriousness, operator layer, and premium execution credibility |
| Membership or continuity layer | Introduce recurring support only after trust is built |
| Final CTA | Push users into command input, consultation, or request submission |

## Trust Building Blocks

The homepage should prove operational credibility, not just taste.

Best trust blocks:

1. clear statement that DALC handles real requests, not just recommendations
2. examples of request categories handled end to end
3. operator-backed execution language
4. high-signal partner and fulfillment proof
5. visible path to paid consultation or structured request handling

## Partner Proof Strategy

Partner proof should support DALC's authority, not replace it.

DALC should say, in effect:

1. we control the request and execution layer
2. we work with trusted specialists where needed
3. we do not dump the user into partner chaos

## Membership Placement

Membership should not appear too early on the page.

It should appear after DALC has established:

1. what the product is
2. why it is different
3. why repeated execution support is valuable

Best placement: after trust and use-case sections, before the final CTA.

## Conversion CTAs

Primary CTA should be command-driven.

Secondary CTA should be for high-trust conversion.

Recommended CTA structure:

1. Primary: Start With A Request
2. Secondary: Book A Consultation

## What Should Be Removed From The Current Homepage Approach

1. any framing that makes DALC feel like a curated catalog first
2. excessive category grids above the main thesis
3. generic luxury-language that does not explain the system
4. lifestyle imagery that overwhelms the relocation and business wedge
5. weak conversion surfaces that do not push high-intent users into the command layer

## Final Recommendation

The homepage should make users feel they have found the system that can actually handle Dubai, not the prettiest website about Dubai.
